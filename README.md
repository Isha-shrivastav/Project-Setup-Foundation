# 📖 Overview

Day 3 focused on preparing the project for scalable development.

Instead of implementing core features, the objective was to create a clean architecture, configure the development environment, establish the project structure, and ensure everything runs successfully.

At the end of this stage, the application launches locally with a working **Hello World** screen and is fully prepared for feature development.

# ⚙ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd project-name
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Backend

```bash

```
